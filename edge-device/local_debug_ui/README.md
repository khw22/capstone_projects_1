# 라즈베리파이 로컬 디버그 UI

이 폴더는 **라즈베리파이(또는 개발용 Debian VM) 엣지 디바이스에서만** 동작하는
**로컬 디버그용 미니 UI** 프로토타입입니다.

운영자용 메인 대시보드가 아닙니다.

## 목적

- 엣지 디바이스 설치/설정 직후의 상태 점검
- USB CCTV 입력 확인
- OCR ROI 좌표 설정 점검
- 모델 로드 상태 / 추론 동작 여부 확인
- 최근 오염도 점수 및 온/습도 값 확인
- 현장 디버깅용 로그 확인

## 포함 항목

- 장치 상태
- 서버 연결 상태
- CCTV 입력 상태
- 현재 프레임 미리보기 (placeholder)
- OCR 상태 / OCR 좌표
- 최근 온도/습도 값
- 모델 상태 / 모델 버전
- 추론 상태
- 최근 오염도 점수
- 최근 로그

## 포함하지 않는 항목

- 지도
- 다중 CCTV 관리
- 장기 통계
- 보고서 생성
- 전체 이벤트 관리
- 운영자용 메인 대시보드 기능

위 항목은 모두 **중앙 서버 대시보드(`server/static_dashboard/`)** 에 속합니다.

## 실행 방법

이 UI는 정적 HTML/CSS/JS 입니다. 별도의 빌드/서버가 필요 없습니다.

옵션 1: 파일을 직접 브라우저로 열기
- 라즈베리파이의 데스크톱 환경에서 `index.html` 더블 클릭

옵션 2: 간단한 정적 서버로 띄우기 (선택)
```
cd edge-device/local_debug_ui
python3 -m http.server 8080
```
그 후 라즈베리파이 로컬 브라우저에서 `http://localhost:8080` 접속.

## 현재 상태

- 백엔드 API 연동 없음
- 정적 placeholder 데이터만 표시
- 실제 OCR / 추론 / 서버 통신은 추후 단계에서 연결
